ALGORITHM IMPLEMENTATION DETAILS
================================================================================

NEAREST NEIGHBOR ALGORITHM (Shortest Path First):

Function: nearestNeighborRoute(bins, startPoint)
Purpose: Calculate optimal collection order minimizing travel distance

Algorithm Steps:
  1. Start at Barangay Hall
  2. For each unvisited bin:
     a. Calculate distance from current position
     b. Find bin with minimum distance
  3. Add that bin to route
  4. Update current position to that bin
  5. Repeat until all bins visited
  6. Add return to Barangay Hall

Complexity:
  Time: O(n²) where n = number of bins
  Space: O(n) for visited tracking
  Typical execution: <100ms for 20 bins

Example:
  Input bins: [
    { id: 1, lat: 13.7565, lng: 121.0583 },
    { id: 2, lat: 13.7570, lng: 121.0590 },
    { id: 3, lat: 13.7558, lng: 121.0575 }
  ]
  
  Calculation:
    Start at Barangay Hall (14.6091, 121.0223)
    Distance to Bin-1: 8.2 km
    Distance to Bin-2: 8.3 km  ← closest (skip)
    Distance to Bin-3: 8.1 km  ← closest
    Result: [Bin-3, Bin-1, Bin-2]

TRUCK MOVEMENT INTERPOLATION:

Function: interpolatePosition(from, to, progress)
Purpose: Smooth truck movement along route segment

Formula:
  position = {
    lat: from.lat + (to.lat - from.lat) × progress,
    lng: from.lng + (to.lng - from.lng) × progress
  }
  where progress = elapsed_time / segment_duration [0 to 1]

Update Frequency: Every 100ms for smooth 10 FPS animation

Example:
  From: Hall (14.6091, 121.0223)
  To: Bin-1 (13.7565, 121.0583)
  Progress: 0.5 (halfway)
  Result: ((14.6091+13.7565)/2, (121.0223+121.0583)/2)
        = (14.1828, 121.0403) ← truck position at 50%

AUTO-COLLECTION TRIGGER:

Function: isAtBinLocation(truckLocation, binLocation, threshold)
Purpose: Detect when truck arrives at bin for automatic collection

Trigger Condition:
  distance(truck, bin) < 0.02 km (~20 meters)

Haversine Distance Formula:
  distance = 2 × R × arctan2(√a, √(1-a))
  where:
    R = 6371 km
    a = sin²(Δlat/2) + cos(lat1)×cos(lat2)×sin²(Δlng/2)

FILL LEVEL ANIMATION:

Duration: 10 seconds
Steps: 20 updates at 500ms intervals
Formula:
  newFillLevel = initialFillLevel × (1 - step/20)
  
Example:
  Initial: 85%
  Step 1: 85 × (1 - 1/20) = 80.75%
  Step 5: 85 × (1 - 5/20) = 63.75%
  Step 10: 85 × (1 - 10/20) = 42.5%
  Step 20: 85 × (1 - 20/20) = 0%
